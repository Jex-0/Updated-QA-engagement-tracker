    ☁ Connect to the Cloud

    So that agents and team leaders on different devices all see the same engagements, connect this app to a free Firebase database (Google Cloud). Do this once per device.

    1. Go to console.firebase.google.com and sign in with a Google account.
    2. Click Add project (e.g. "Client-Engagement-Tracker") and create it.
    3. In the project, click Build → Firestore Database → Create database. Choose production mode and a location near you.
    4. In Authentication → Sign-in method, enable Anonymous and save.
    5. Open Firestore Database → Rules and paste: 
      rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /engagements/{document} {
      allow read, write: if request.auth != null;
    }
  }
}
      Then click Publish.
    6. Click Project settings (gear) → Your apps → Web app (</>). Register a web app and copy the firebaseConfig object.
    7. Paste it below and click Save & Connect.
